📌 FAQ & Panduan Lengkap Aplikasi

Aplikasi ini dirancang untuk mengelola data pegawai Pemerintah dengan Perjanjian Kerja (PPPK) Paruh Waktu di lingkungan Kementerian Sosial, mulai dari input data satuan, import data massal dari Excel, pengunggahan dokumen pendukung (Surat Persetujuan dan Perjanjian Kerja) secara otomatis, hingga pencarian dan pencetakan daftar nominatif per Satuan Kerja.

Batas akhir pengusulan dan pengisian data adalah tanggal 30 September 2026. Pastikan seluruh kelengkapan data dan dokumen terunggah sebelum batas waktu tersebut.

Format nama file wajib: NIP_NamaPanggilan.pdf (Contoh: 199004052026011001_Toni.pdf). Maksimal upload adalah 50 file PDF per sekali proses.

Masuk ke tab Upload Surat Persetujuan, ketik atau pilih Satuan Kerja dari database, lalu pilih file PDF surat persetujuannya. Sistem akan otomatis menautkan dokumen tersebut ke seluruh pegawai pada Satuan Kerja terpilih.

Anda dapat menggunakan fitur Live Chat Asisten di bawah atau mengirimkan tiket laporan melalui formulir Buat & Riwayat Tiket Pelaporan di sebelah kanan. Tim helpdesk akan segera memeriksa dan memberikan respon.
